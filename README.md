# お出かけ天気プランナー

日本の地域名を入力して、現在の天気・気温・風速を確認できるWebアプリです。
HTML・CSS・JavaScriptとAPI通信を学ぶために制作しました。

## デモ

https://bot-of-flesh.github.io/outdoor-weather-plannner/

## 主な機能

- 日本語の地域名から位置を検索
- 現在の天気・気温・風速を表示
- 気温に応じた外出時のアドバイスを表示
- 読み込み中の表示とエラーメッセージ
- ボタンのクリック・Enterキーで検索

## 使い方

1. 地域名を入力します（例：群馬県太田市）。
2. 「天気を調べる」を押します。
3. 天気とアドバイスを確認します。

## 使用技術・データ

- HTML / CSS / JavaScript
- Fetch API / async・await
- 国土地理院：地名・位置情報
- Open-Meteo：天気情報

出典：
- [国土地理院](https://maps.gsi.go.jp/)
- [Open-Meteo](https://open-meteo.com/)

## ローカルでの起動

このリポジトリをダウンロードし、VS CodeのLive Serverで
index.htmlを開いてください。天気の取得にはインターネット接続が必要です。

## 現在の制限

- 地名検索では最初の検索結果を使用します。
- 都道府県を検索した場合、代表地点の天気を表示します。
- アドバイスは気温だけを基準にした簡単な目安です。
